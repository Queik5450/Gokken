Acerca de Gokken

Gokken es una plataforma web para explorar videojuegos: rankings, lanzamientos, compañías, consolas, eventos y noticias. Integra datos de IGDB y agrega noticias reales vía RSS.

Volver al inicio Ver tecnologías

¿Qué es Gokken?

Exploración

Búsqueda y navegación por juegos, compañías y consolas con resultados rápidos.

Rankings

Top 100 y listados con filtros, enfocados en descubrir lo mejor.

Noticias y eventos

Eventos desde IGDB y noticias reales desde RSS (priorizando fuentes en español).

Tecnologías utilizadas

Frontend

  • HTML5 + CSS3
  • JavaScript (Vanilla)
  • Tailwind CSS (CDN) + estilos propios
  • Font Awesome + Google Fonts

Backend

  • Node.js + Express
  • axios (requests), cors, dotenv
  • rss-parser (agregación de noticias)
  • Proxy API local (por defecto en :8080)

APIs / Fuentes

  • IGDB API (datos de juegos/compañías/eventos)
  • Twitch OAuth (token para IGDB)
  • RSS (noticias reales sin API key)

Buenas prácticas

  • Separación frontend/back (archivos estáticos + API)
  • Cache de token y cache de RSS con TTL
  • Normalización de datos para la UI
